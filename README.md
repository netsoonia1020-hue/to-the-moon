# 등대지기의 오르골

어느 유품정리사가 본, 여섯 음의 기억 — 스토리 중심 픽셀 어드벤처 (약 30분, 엔딩 5개).

《To the Moon》처럼 **한 사람의 기억을 거꾸로 거슬러 올라가는** 구조를 참고했지만, 이야기·인물·그림·음악은 모두 새로 만든 오리지널입니다.

## 줄거리
유품정리사 **서윤**은 평생 등대지기로 산 고(故) 한정우의 집을 정리하러 온다. 하나뿐인 딸 미래는 "전부 처리해 달라"고만 한다.
오래 사랑받은 물건의 기억을 볼 수 있는 서윤은 고장 난 오르골을 따라 시간을 거슬러 내려간다.
그리고 서윤에게는, 이 집을 자원한 이유가 따로 있다.

## 플레이
- `index.html`을 브라우저로 열면 실행됩니다 (설치·빌드 없음). 플레이 시간 약 1시간 (음성 낭독 포함 추정).
- 이동: 방향키 / WASD · 조사·대화: Space / Enter
- 모바일: **화면 아무 곳이나 누르면 그 자리에 조이스틱**이 생깁니다. 짧게 톡 치면 조사.
- 각 기억에서 빛나는 **기억의 조각** 3개를 찾으면 다음 장이 열립니다. 제5장에는 렌즈 닦기·추 감기·주파수 맞추기 미니게임이 있습니다.
- 희미하게 반짝이는 **미래의 조각**(선택 수집 6개)과 전화 통화, 오르골 수리 결과가 엔딩을 가릅니다.
- 화면 위 `🔊 소리` / `🗣 음성` / `💾 저장` 버튼. 저장은 슬롯 3개 + 자동 저장.
