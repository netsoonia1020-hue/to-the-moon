# 등대지기의 오르골

어느 유품정리사가 본, 여섯 음의 기억 — 짧은 스토리 중심 픽셀 게임 (약 15분).

《To the Moon》처럼 **한 사람의 기억을 거꾸로 거슬러 올라가는** 구조를 참고했지만, 이야기·인물·그림·음악은 모두 새로 만든 것입니다.

## 줄거리
유품정리사 **서윤**은 평생 등대지기로 산 고(故) 한정우의 집을 정리하러 온다. 하나뿐인 딸 미래는 전화로 "전부 처리해 달라"고만 한다.
오래 사랑받은 물건에 손을 대면 그 물건의 기억을 볼 수 있는 서윤은, 고장 난 오르골을 따라
2019년 → 1998년 → 1976년의 기억으로 내려가며 끝내 완성되지 못한 노래의 여섯 음을 모은다.

## 플레이
- `index.html`을 브라우저로 열면 바로 실행됩니다 (설치·빌드 필요 없음, 파일 하나).
- 이동: 방향키 / WASD · 조사·대화 넘기기: Space / Enter
- 모바일: 화면의 방향 버튼과 「조사」 버튼
- 각 기억에서 빛나는 **기억의 조각** 3개를 찾으면 다음 기억으로 가는 길이 열립니다.
- 마지막에 모은 음으로 오르골 원통에 핀을 꽂아 노래를 되살립니다.

## 기술 메모
- 순수 HTML/JS + Canvas, 외부 에셋 없음. 그래픽은 코드로 그린 픽셀 아트, 음악·효과음은 WebAudio로 실시간 합성.
- 개발용 바로가기: `index.html#m1`, `#m2`, `#m3` (각 기억), `#p1` (기억을 다 본 뒤의 현재).
