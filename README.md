# 등대지기의 오르골

어느 유품정리사가 본, 여섯 음의 기억 — 스토리 중심 픽셀 어드벤처 (약 30분, 엔딩 5개).

《To the Moon》처럼 **한 사람의 기억을 거꾸로 거슬러 올라가는** 구조를 참고했지만, 이야기·인물·그림·음악은 모두 새로 만든 오리지널입니다.

## 줄거리
유품정리사 **서윤**은 평생 등대지기로 산 고(故) 한정우의 집을 정리하러 온다. 하나뿐인 딸 미래는 "전부 처리해 달라"고만 한다.
오래 사랑받은 물건의 기억을 볼 수 있는 서윤은 고장 난 오르골을 따라
**2019 → 2008 → 1998 → 1985 → 1976** 다섯 개의 기억으로 내려가, 끝내 완성되지 못한 노래의 여섯 음을 모은다.

## 플레이
- `index.html`을 브라우저로 열면 실행됩니다 (설치·빌드 없음).
- 이동: 방향키 / WASD · 조사·대화: Space / Enter · 모바일: 화면 버튼
- 각 기억에서 빛나는 **기억의 조각** 3개를 찾으면 다음 기억이 열립니다.
- 희미하게 반짝이는 **미래의 조각**(선택 수집 5개)과 전화 통화, 오르골 수리 결과가 엔딩을 가릅니다.
- 화면 위 `🔊 소리` / `🗣 음성` 버튼으로 소리와 낭독을 켜고 끕니다. 진행은 자동 저장됩니다.

## 저작권
- 그림: 전부 코드로 그린 픽셀 아트 (외부 이미지 없음)
- 음악·효과음: WebAudio 실시간 합성, 멜로디는 자작
- 낭독 음성: 기기 내장 TTS(Web Speech API)를 실시간 호출 — 음성 파일을 포함하지 않음
- 외부 에셋·라이브러리 0개

## 구조
```

css/style.css       UI 스타일
js/core.js          엔진: 오디오·음성·대화·연출·입력·저장
js/art.js           스프라이트·타일·사물·조명·전경 일러스트
js/scenes.js        장면·대본·퍼즐·엔딩
manifest.webmanifest, sw.js, icon.png   설치형 웹앱(PWA)용
```
